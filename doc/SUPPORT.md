# PulseBar 支持与已知限制

更新日期：2026-08-31
适用版本：PulseBar 1.0.x

## 获取支持

请在 [GitHub Issues](https://github.com/xiaolin0429/PulseBar/issues) 提交缺陷或功能建议。提交前建议先搜索已有 Issue，并提供可复现且不包含敏感信息的诊断背景。

对于可能涉及安全或隐私的问题，请只描述影响、版本和安全的复现边界，不要在公开 Issue 中粘贴密码、Cookie、令牌、会话、个人文件内容或可识别个人身份的数据。

## 支持范围

- 最低系统：macOS 13。
- 架构目标：Apple Silicon `arm64` 与 Intel `x86_64`；各架构的真实发行支持以[发布清单](RELEASE_CHECKLIST.md)中的实机验收状态为准。
- 数据来源：公开系统 API；不依赖命令行子进程、私有框架或特权 Helper。
- 正式功能范围：CPU、内存、磁盘、网络、最近内存趋势、菜单栏摘要和本地设置。

## 已知限制

- PulseBar 与活动监视器的采样窗口和内存口径不同，瞬时值可能不完全一致，长期趋势应保持一致。
- 某些硬件或沙盒环境可能不提供 IOKit 磁盘累计计数；此时容量继续显示，I/O 速率独立降级为不可用。
- PulseBar 使用普通可用块统计卷容量。APFS 快照、可清除空间和 Finder 的展示口径可能造成数值差异。
- VPN、接口切换、睡眠/唤醒和计数器回绕会重建速率基线；预热期间暂不显示速率，避免错误尖峰。
- 菜单栏空间不足时，macOS 可能暂时隐藏项目。可减少模块、切换简洁密度，或重新打开应用恢复菜单栏项目。
- v1.0 不包含告警、通知、长期历史、导出、进程排行、温度、GPU 或风扇数据。

## 缺陷报告建议

请尽量提供：

- macOS 版本、Mac 型号和芯片架构；
- PulseBar 版本、Build 号和安装来源；
- 发生问题的模块、刷新策略和复现步骤；
- 预期结果与实际结果；
- 是否处于 VPN、外接磁盘、睡眠/唤醒、网络切换或低磁盘空间场景；
- 经检查不含个人信息的截图或日志片段。
