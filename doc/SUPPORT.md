# 支持与已知限制

## 支持范围

- 最低系统：macOS 13。
- 架构：arm64 与 x86_64 构建目标；发布前需分别完成实机验证。
- 数据来源：公开系统 API；不依赖命令行子进程、私有框架或特权 Helper。

## 已知限制

- PulseBar 与活动监视器的采样窗口和内存口径不同，瞬时数值可能不完全一致，趋势应保持一致。
- 某些硬件或沙盒环境可能不提供 IOKit 磁盘累计计数；此时容量继续显示，I/O 速率降级为不可用。
- APFS 快照和可清除空间可能导致可用容量与 Finder 略有差异。
- VPN、接口切换、睡眠唤醒和计数器回绕会重建速率基线，短暂显示预热状态，避免错误尖峰。
- 菜单栏空间不足时 macOS 可能暂时隐藏项目；可减少模块、切换简洁密度，或重新打开应用恢复菜单栏项目。
- v1.0 不包含告警、通知、长期历史、导出、进程排行、温度或风扇数据。

## 反馈时建议提供

- macOS 版本和 Mac 芯片；
- PulseBar 版本与构建号；
- 发生问题的模块、刷新策略和复现步骤；
- 是否处于 VPN、外接磁盘、睡眠唤醒或网络切换场景。

请勿提交 Cookie、令牌、密码、会话信息或其他敏感数据。正式发布前，应在 App Store 页面和项目主页补充实际支持渠道。
