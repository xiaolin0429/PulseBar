## 2. 产品定义

PulseBar 是一款原生 macOS 菜单栏系统监控工具。它以一个紧凑的菜单栏项目持续呈现核心状态，并在点击后提供 CPU、内存、磁盘和网络的详细数据及最近趋势。

### 2.1 产品目标

- 用户无需打开活动监视器即可快速判断系统是否繁忙。
- 在有限菜单栏空间中同时表达多个关键指标。
- 数据口径透明，异常和不可用状态不伪装成零值。
- 应用自身保持低 CPU、低内存、低唤醒和零外部网络连接。
- 所有运行时功能使用公开系统 API，并适配 App Sandbox。

### 2.2 产品原则

1. **小而美**：功能聚焦，常驻资源开销必须与工具价值相称。
2. **一眼可读**：菜单栏优先传达状态，不堆叠冗余标签。
3. **本机优先**：指标只在进程内处理，不上传，不跨启动保存历史。
4. **诚实降级**：预热、过期、失败和不支持必须有独立状态。
5. **原生体验**：遵循 macOS 菜单栏、设置、登录项和辅助功能规范。
6. **公开边界**：源码仓库公开，正式功能和未交付规划在文档中明确区分。

## 3. 目标用户与场景

### 3.1 目标用户

- 希望随时了解 Mac 负载的普通用户；
- 开发、设计、音视频和数据工作者；
- 需要观察短时性能变化但不需要专业诊断套件的用户；
- 重视隐私、无广告和低资源占用的用户。

### 3.2 核心场景

- 编译、渲染或会议时快速确认 CPU 与内存压力；
- 下载、同步或 VPN 切换时观察网络吞吐；
- 磁盘空间不足前查看系统数据卷和本地卷容量；
- 发现瞬时异常后打开面板查看最近 60 秒至 5 分钟趋势；
- 菜单栏空间不足时切换密度、隐藏模块或调整顺序。

## 4. 版本范围

### 4.1 v1.0 正式范围

- 单一组合菜单栏项目；
- CPU、内存、磁盘、网络四类模块；
- 简洁、标准、完整三档菜单栏密度；
- 模块开关、垂直拖拽排序和一位小数选项；
- 详细监控面板和内存趋势图；
- 暂停/继续、活动监视器入口和退出；
- 自适应及固定刷新策略；
- 60 秒、2 分钟、5 分钟历史窗口；
- 容量与速率单位设置；
- 登录时启动、Dock 图标、重新打开行为；
- 简体中文、英文、VoiceOver、浅色/深色和高对比度；
- 首次启动说明、菜单栏恢复入口、隐私与关于信息。

### 4.2 v1.0 不包含

- 阈值告警、本地通知和免打扰；
- 长期历史、跨启动保存、CSV/JSON 导出；
- 手动指定或同时展示全部网络接口；
- 电池、GPU、温度、风扇和传感器；
- 进程排行、进程结束或其他管理操作；
- 云同步、账户、远程监控或团队能力。

这些能力不得出现在 v1.0 商店宣传的已交付列表中。

## 5. 信息架构

PulseBar 由五个用户可见入口组成：

1. **菜单栏摘要**：持续显示已选模块。
2. **监控面板**：点击菜单栏项目后展示完整状态。
3. **设置窗口**：通用、菜单栏、监控、隐私与关于四个标签页。
4. **首次启动窗口**：解释菜单栏位置、隐私和基础使用方式。
5. **恢复窗口**：菜单栏项目被系统移除后，为重新插入提供明确入口。

## 6. 菜单栏摘要

### 6.1 通用要求

- 仅创建一个 `MenuBarExtra`。
- 默认模块为 CPU、内存和网络。
- 至少保留一个可见模块。
- 模块顺序与设置页一致，重启后保持。
- 菜单栏刷新不得使用隐式动画，避免数字更新产生位移。
- 项目空间不足时，用户可以切换简洁密度或减少模块。
- VoiceOver 将摘要朗读为完整语义，不依赖视觉缩写。

### 6.2 密度

| 密度 | 布局 | 内容 |
|---|---|---|
| 简洁 | 单行、11 pt 圆角等宽数字 | 每个模块的最核心值 |
| 标准 | 两行、8 pt 等宽半粗体模板图 | CPU、内存和网络等多列紧凑摘要 |
| 完整 | 两行模板图 | 在标准能力上允许显示磁盘模块 |

标准和完整密度采用有界模板图渲染，以稳定控制 `MenuBarExtra` 的两行字体、行距和宽度。磁盘模块只在完整密度中显示，设置页必须明确说明。

### 6.3 模块表达

- CPU：百分比；两行模式下底部标签为 CPU。
- 内存：百分比；两行模式下底部标签为 MEM。
- 网络：下载和上传速率；简洁模式优先显示下载。
- 磁盘：主卷普通可用容量；两行模式下底部标签为 SSD。
- 不可用数据使用破折号，不显示虚假的 0。
- 数值严重程度可以改变模板前景色，但不得仅依赖颜色传达状态。

## 7. 监控面板

### 7.1 整体布局

- 固定宽度 420 pt，高度在 500–720 pt 内适配。
- 顶部显示设备名称、监控状态、最近更新时间和系统运行时间。
- 顶部提供暂停/继续和设置按钮。
- 中部滚动区域按 CPU、内存、磁盘、网络排列四张卡片。
- 底部提供活动监视器和退出入口。

### 7.2 卡片规则

每张卡片包含：

- 模块名称和图标；
- 主要指标；
- 必要的拆分指标；
- 最近趋势；
- 可展开的数据口径说明；
- 预热、过期或不可用状态。

展开或闭合口径说明时，卡片和趋势图属于同一布局动画，必须同步移动，不得出现短暂错位。

### 7.3 设置按钮

- 第一次点击必须创建并显示设置窗口。
- 设置窗口已经存在但被其他应用覆盖时，再次点击必须激活 PulseBar 并将窗口前置。
- 设置窗口关闭后，再次点击必须重新创建。
- 任一情况下不得产生重复设置窗口。

## 8. 指标需求与口径

### 8.1 CPU

展示：

- 总占用率；
- 用户占用率和系统占用率；
- 逻辑核心数；
- 1、5、15 分钟负载平均值；
- 总占用最近趋势。

口径：

- 通过 `host_processor_info` 读取每个逻辑处理器累计 tick；
- 使用相邻样本差值计算用户、系统、nice 和 idle；
- 总占用为非 idle 差值占总差值比例；
- 第一个样本仅建立基线，显示预热；
- 计数异常或时间窗无效时重建基线，不输出 NaN、负数或大于 100% 的值。

### 8.2 内存

展示：

- 物理内存总量；
- 近似已用和近似可用；
- 活跃、非活跃、联动、压缩、可清除；
- Swap 已用和总量；
- normal、warning、critical 或 unknown 压力状态；
- 已用比例最近趋势。

口径：

- VM 页计数来自 `host_statistics64` 和 `host_page_size`；
- Swap 来自 `sysctlbyname(vm.swapusage)`；
- 压力来自系统内存压力事件；
- “已用”是适合趋势监控的近似值，不宣称与活动监视器逐字节一致；
- UI 必须提供口径说明，解释采样窗口和系统工具的差异。

### 8.3 磁盘

展示：

- 系统数据卷及本地卷名称、总容量、普通可用容量和已用比例；
- 整机聚合读取/写入速率；
- 读取与写入最近趋势；
- I/O 不可用时，容量仍继续展示。

口径：

- 使用 `FileManager.mountedVolumeURLs` 和公开 URL 元数据枚举本地卷；
- 容量通过 Darwin `statfs` 读取总块和普通可用块；
- 不请求“重要用途可用容量”，避免触发可清理空间扫描；
- 普通可用容量可能与 Finder 含可清理空间的口径不同；
- I/O 通过 IOKit 块存储累计计数的相邻样本差值计算；
- 卷容量属于低频数据，配置变化或低频周期才刷新。

### 8.4 网络

展示：

- online、offline、requires connection 或 unknown 路径状态；
- 自动选择的系统主接口名称与类型；
- 下载和上传速率；
- 本次应用运行期间的下载和上传累计量；
- 下载和上传最近趋势。

口径：

- `NWPathMonitor` 提供路径状态；
- SystemConfiguration 解析系统主接口；
- `getifaddrs` 读取接口累计字节；
- 接口切换、计数器回绕、睡眠/唤醒或时间窗异常时重建基线；
- 会话累计量只保存在内存中，应用退出后清除；
- v1.0 不提供手动接口选择。

## 9. 采样、历史与生命周期

### 9.1 刷新策略

| 策略 | 面板可见 | 面板隐藏 |
|---|---:|---:|
| 自适应 | 1 秒 | 2 秒 |
| 每 1 秒 | 1 秒 | 1 秒 |
| 每 2 秒 | 2 秒 | 2 秒 |
| 每 5 秒 | 5 秒 | 5 秒 |

要求：

- 四类指标在同一采样轮次中并发读取。
- 协调器必须保证同一轮次只有一个生命周期所有者。
- 采样循环允许 10% 定时容差以减少无意义唤醒。
- 暂停或睡眠时取消循环。
- 继续或唤醒时先重建差值基线，再恢复展示。

### 9.2 历史

- 每条序列使用固定容量 360 的环形缓冲区。
- 用户可选择 60、120 或 300 秒显示窗口。
- 只有面板可见时才物化历史数组并发布给 SwiftUI。
- 绘制前最多保留 60 点，同时保留每个有序桶的局部峰谷。
- 历史不落盘，不跨启动，不上传。

### 9.3 面板隐藏

面板关闭后：

- 清除完整快照和历史数组的展示状态；
- 卸载完整卡片与图形树，使用同尺寸静态壳维持窗口布局；
- 菜单栏继续接收轻量摘要；
- 不为隐藏界面物化趋势数组。

## 10. 设置需求

### 10.1 通用

- 登录时自动启动，默认关闭；
- 在 Dock 中显示图标，默认关闭；
- 重新打开应用时仅保持菜单栏或同时打开监控面板；
- 界面语言：跟随系统、简体中文、English；
- 恢复默认设置并二次确认；
- 登录项需要系统批准或当前构建不支持时给出明确说明。

### 10.2 菜单栏

- 实时预览；
- 简洁、标准、完整密度；
- 是否显示一位小数；
- CPU、内存、磁盘、网络模块开关；
- 右侧句柄垂直拖拽整行排序；
- 拖拽视觉只能沿 Y 轴移动，不跟随横向指针漂移；
- Switch 位置对齐；
- 提供上移/下移上下文菜单和辅助功能可调操作。

### 10.3 监控

- 刷新策略：自适应、1 秒、2 秒、5 秒；
- 历史窗口：60 秒、2 分钟、5 分钟；
- 单位：默认混合、十进制 SI、二进制 IEC；
- 网络接口由系统自动选择；
- 磁盘默认使用系统数据卷；
- 睡眠时暂停为固定安全行为。

### 10.4 隐私与关于

- 明示无数据收集、无外部网络连接；
- 展示无需管理员、完全磁盘访问和辅助功能权限；
- 展示版本与系统 API 来源；
- 不展示尚未实现的告警设置。

## 11. 状态、错误与恢复

所有模块使用统一状态语义：

- `available`：数据有效；
- `warmingUp`：正在建立差值基线；
- `stale`：保留最近有效值并携带年龄；
- `unavailable`：包含稳定错误码、用户文案键和仅本地调试上下文。

要求：

- 单模块失败不得停止其他模块。
- 用户首屏文案保持简洁，技术细节不直接暴露。
- 暂停状态必须清晰且可恢复。
- 菜单栏项目被系统移除时，下次启动显示恢复入口。
- 设置持久化数据必须归一化；空模块列表自动恢复至少一个模块。

## 12. 辅助功能与本地化

- 正式语言为简体中文和英文；“跟随系统”按当前 Locale 选择。
- 所有用户可见字符串进入 String Catalog。
- 菜单栏摘要、图表、按钮、开关和状态具有 VoiceOver 标签。
- 图表提供文本摘要，不要求用户读取折线。
- 拖拽排序同时提供辅助功能增减操作和上下文菜单。
- 支持键盘导航、浅色、深色、增加对比度和减少动态效果。
- 固定尺寸窗口与菜单栏文本不得在两种语言中出现关键内容截断。

## 13. 隐私与安全

- App Sandbox 开启。
- 不启用 Incoming/Outgoing Network entitlement。
- 不请求管理员权限、完全磁盘访问或辅助功能权限。
- 不读取文件内容或其他应用数据。
- 不引入广告、分析、遥测、崩溃上传或第三方运行时 SDK。
- 设置仅写入应用沙盒内 `UserDefaults`。
- 指标和历史仅在内存中处理。
- 最终 App Store 隐私申报必须与归档 Privacy Report 一致。

## 14. 非功能目标

### 14.1 性能预算

- 单轮四类原始采集应显著低于刷新间隔，超过 20 ms 记录本地 notice。
- 原始采集 P95 预算：CPU 3 ms、内存 3 ms、网络 3 ms、磁盘 I/O 8 ms、低频卷容量 20 ms。
- 默认自适应、面板隐藏的常驻 CPU 目标低于 1%，短时系统调度抖动单独记录。
- 面板持续绘制的 physical footprint 峰值预算低于 60 MB。
- 五分钟稳态增长预算不超过 10 MB。
- 面板隐藏后不保留完整图形展示树与历史数组。

### 14.2 稳定性

- 8 小时默认策略无崩溃、无持续增长和无异常外部连接。
- 24 小时用于发行候选长稳观察。
- 睡眠/唤醒后五秒内恢复，不产生错误速率尖峰。
- 卷和网络接口变化不导致整个应用失效。

### 14.3 兼容性

- 最低 macOS 13。
- 构建目标为 arm64 与 x86_64。
- 发行前覆盖 macOS 13、14、15、当前稳定版和至少一台 Intel Mac。
- 当前 x86_64 仅有交叉编译证据，不能标记为实机通过。

## 18. 已确认的产品决策

1. 最低系统为 macOS 13。
2. 使用一个组合 `MenuBarExtra`，不为每个指标创建独立项目。
3. v1.0 只提供内存中的最近趋势，不提供持久化历史。
4. 趋势图使用 SwiftUI `Shape` / `Path`，不使用 Swift Charts。
5. 磁盘容量使用 `statfs` 普通可用块，不计算可清理空间。
6. 四类采集在同一轮次结构化并发执行。
7. 告警和通知属于 v1.1，不链接到 v1.0 运行路径。
8. 指标失败独立降级，不以 0 值掩盖异常。
9. 公开仓库为 <https://github.com/xiaolin0429/PulseBar>。
